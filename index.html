01 / SHOP CARD

ショップカードの運用

ご来店の楽しみが次につながる、LINE上のポイントカードです。

FOR CUSTOMERS

お客様の操作

  1. ショップカードを開くLINEのトーク画面またはリッチメニューからショップカードを開きます。
  2. ポイント付与QRコードを読み取るショップカードの［QRコードをスキャン］を選び、店舗スマホに表示されたポイント付与用QRコードを読み取ります。
  3. 取得ポイントを確認するポイント獲得結果が表示され、ショップカードのポイント数が増えたことを確認します。
  4. 特典を利用する必要ポイントに達すると表示される特典チケットを店舗スタッフに提示します。店舗での最終操作は、チケットの内容と有効期限を確認してから行います。

FOR STORE STAFF

店舗スタッフの操作

店舗側がポイントを直接入力する操作ではありません。店舗スマホにポイント付与用QRコードを表示し、お客様自身のLINEで読み取っていただきます。

  1. 店舗スマホを準備する通信状態を確認し、最新版の「LINE公式アカウント」管理アプリを開きます。THE WINE BASEを管理できるアカウントでログインし、対象アカウントを選びます。
  2. ポイント付与用QRコードを表示する管理アプリの［ホーム］→［ショップカード］を開き、メニューから［スマートフォンにQRコードを表示］を選びます。今回付与するポイント数・条件を確認して表示します。
  3. お客様にQRコードを提示するお客様のLINEでショップカードを開き、［QRコードをスキャン］から店舗スマホのQRコードを読み取っていただきます。
  4. ポイント反映を確認するお客様の画面にポイント獲得結果が表示され、ポイント数が増えたことを一緒に確認します。必要に応じて管理側の［ポイント付与履歴］も確認します。
  5. 特典の利用に対応するお客様が提示した特典チケットの内容と有効期限を確認します。利用済みにする具体的な店舗操作は、現在の管理画面で確認してください。要確認
接客のひとこと

「LINEのショップカードにポイントが貯まります。よろしければこちらを読み取ってください。」

FOR ADMINISTRATORS

カードの管理

  1. ショップカードを新規作成する管理アプリの［ホーム］→［ショップカード］→［ショップカード設定］で必要項目を入力し、下書き保存または公開します。
  2. 特典チケットを追加・設定するショップカード作成画面のゴール特典から［特典チケットを作成］を選び、特典内容と有効期限などを設定して保存します。
  3. ランクアップカードを設定するショップカード作成後に［ランクアップカードを作成］を選び、ランクアップ条件とカード内容を設定して保存します。
  4. ポイント付与用QRコードを設定するショップカードのメニューから付与ポイント数や読み取り期限を設定します。印刷用QRコードとスマートフォン表示用のワンタイムQRコードを用途に合わせて使い分けます。
  5. ショップカードを公開する設定内容を確認して［保存してカードを公開］を選びます。公開前に、特典・有効期限・ポイント付与条件を必ず照合します。
  6. カードの設定・利用履歴を確認するショップカードの設定画面と［ポイント付与履歴］を確認します。集計値は管理画面の［分析］→［ショップカード］でも確認できます。
  7. ショップカードの公開を停止する［ショップカード］→［設定］から公開停止を行います。公開停止は元に戻せず、お客様の保有ポイントを含むカード情報が削除されます。実行前に必ず管理者が影響を確認してください。
  8. カードの削除方法・可否を確認するショップカード単体の「削除」は公式資料で確認できていません。「公開停止」とは別の操作として扱い、現在の管理画面と公式サポートで可否を確認してください。要確認
THE WINE BASE 運用予定
  • トレーニングカード：3ポイントでランクアップ
  • 通常運用カード：ポイント付与は1日1回まで
  • 通常運用カード：3ポイント単位で特典、15ポイントで満了

※管理画面の実設定は未確認です。運用開始前に、公開中カードの設定値と付与QRコードの条件を管理者が照合してください。

TROUBLESHOOTING

困ったとき

  1. QRコードが読み取れない店舗スマホの画面の明るさ、通信状態、カメラの汚れ、QRコードの読み取り期限を確認します。ワンタイムQRコードは再利用・印刷せず、新しいQRコードを表示します。
  2. ポイントが付与されない対象カード、カードの公開状態、通信状態、QRコードの有効性、当日の取得制限を順に確認します。二重付与を避けるため、再試行前にお客様のカードと［ポイント付与履歴］を確認します。
  3. 誤ってポイントを付与したまず［ポイント付与履歴］で対象日時と付与内容を確認し、管理者へ連絡します。取り消し・調整方法は公式資料で確認できていないため、自己判断で追加操作をしないでください。要確認
  4. 特典が表示されないお客様のポイント数が必要数に達しているか、対象のショップカードを開いているかを確認します。管理側では特典チケットの設定と有効期限を確認してください。
  5. カードが見つからないTHE WINE BASE公式LINEのトーク画面とリッチメニューを確認します。表示経路や案内リンクが見つからない場合は、管理者に現在の公開設定を確認してください。要確認
  6. 店舗スマホで管理できない通信状態、管理アプリの更新、ログイン中のアカウント、選択中の公式アカウントを確認します。改善しない場合は、管理権限の有無を管理者に確認してください。要確認

03 / MESSAGE

メッセージ配信

読みやすく、来店のきっかけになる情報を、適切なタイミングで届けます。

配信前チェック

  • 目的は明確か新商品、イベント、営業案内など、1配信1テーマに絞ります。
  • 情報は正確か日時・価格・在庫・リンク先を必ず見直します。
  • スマートフォンで読みやすいか文章を短く区切り、テスト配信で見え方を確認します。
配信の基本

タイトル → 要点 → 詳細 → 来店・予約などの次の行動、の順にまとめると伝わりやすくなります。
