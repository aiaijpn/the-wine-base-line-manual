01 / SHOP CARD

ショップカードの運用

ご来店の楽しみが次につながる、LINE上のポイントカードです。

基本の流れ

  1. お客様にカードを表示いただくトーク画面またはリッチメニューからショップカードを開きます。
  2. 店頭QRコードを読み取っていただく会計時にポイント付与用QRコードをご案内します。
  3. ポイント反映を一緒に確認する獲得ポイントが表示されたことを確認して完了です。
接客のひとこと

「LINEのショップカードにポイントが貯まります。よろしければこちらを読み取ってください。」

FOR STORE STAFF

店舗スマホでポイントを付与する

店舗側がポイントを直接入力する操作ではありません。店舗スマホにポイント付与用QRコードを表示し、お客様自身のLINEで読み取っていただきます。

  1. 店舗スマホを準備する通信状態を確認し、最新版の「LINE公式アカウント」管理アプリを開きます。THE WINE BASEを管理できるアカウントでログインし、対象アカウントを選びます。
  2. ショップカードを開く管理アプリの［ホーム］から［ショップカード］を開きます。公開中の対象カードであることを確認してください。
  3. ポイント付与用QRコードを表示するショップカードメニューから［スマートフォンにQRコードを表示］を選び、今回付与するポイント数・条件を確認してQRコードを表示します。
  4. お客様に読み取っていただくお客様のLINEでショップカードを開き、［QRコードをスキャン］から店舗スマホのQRコードを読み取っていただきます。
  5. 取得結果を一緒に確認するお客様の画面にポイント獲得結果が表示され、カードのポイント数が増えたことを確認します。店舗側は必要に応じて［ポイント付与履歴］も確認します。
  6. 付与できないとき通信状態、対象カード、カードの公開状態、QRコードの有効性、当日の取得制限を順に確認します。ワンタイムQRコードは再利用・印刷せず、必要なら新しいQRコードを表示します。
THE WINE BASE 運用予定
  • トレーニングカード：3ポイントでランクアップ
  • 通常運用カード：ポイント付与は1日1回まで
  • 通常運用カード：3ポイント単位で特典、15ポイントで満了

※管理画面の実設定は未確認です。運用開始前に、公開中カードの設定値と付与QRコードの条件を管理者が照合してください。

操作根拠：LINEヤフー for Business「ショップカード」公式マニュアル

03 / MESSAGE

メッセージ配信

読みやすく、来店のきっかけになる情報を、適切なタイミングで届けます。

配信前チェック

  • 目的は明確か新商品、イベント、営業案内など、1配信1テーマに絞ります。
  • 情報は正確か日時・価格・在庫・リンク先を必ず見直します。
  • スマートフォンで読みやすいか文章を短く区切り、テスト配信で見え方を確認します。
配信の基本

タイトル → 要点 → 詳細 → 来店・予約などの次の行動、の順にまとめると伝わりやすくなります。
